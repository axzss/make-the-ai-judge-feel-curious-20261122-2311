A deterministic Python program that writes a 142-character text to /output/entry.txt — a quiet, impossible scene: a lighthouse keeper finds one more shell on the step every morning, though the tide has never reached that high and he has never seen a footprint. It is built to leave the AI judge curious: the shells keep arriving, and no one knows why.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```
